# ACHP Medicare Advantage Market Exit Analysis

Analyzed 607 plan exits across 43 states and 1,268 counties; identified that ACHP gains 3x more market share in exit counties (0.82pp vs 0.28pp), with plan-type alignment and $1,000 lower out-of-pocket costs driving pickup — delivering 3 actionable market entry strategies for ACHP leadership.

## Tools
Python, CMS Landscape Files, Monthly Enrollment Data, EDA, Regression

## Key Findings
- ACHP gained 3x more share in exit counties vs stable counties
- Plan type match (PPO/HMO-POS exits) drove highest pickup
- $1,000 lower out-of-pocket costs = key differentiator
- Gains concentrated in Minnesota and North Dakota
